## 🚀 Как пользоваться
1. Установи Python 3.10 или новее (см. [главу 1](01-basics/01-intro.md)).
2. Склонируй репозиторий:
   ```bash
   git clone https://github.com/<твой-ник>/python-guide.git
   cd python-guide
   ```
3. Читай главы по порядку и **обязательно запускай примеры сам**. Программированию учатся руками, а не глазами.
4. После каждой главы решай задачи. Решения лежат в [exercises/](exercises/01-basics/), но сначала попробуй сам.
